# Round 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship round 4 of the Dulce Kiwi homepage:
- a logo-left header;
- wobbly hero and Special photos;
- a scroll-pinned "drum" About Me section with doodles;
- a physics pantry shelf behind the contact section;
- a phone pass over the hero, Special, bakes, Cómo pedir and the floating pill.

**Architecture:**
- **Pure logic in plain `.ts` modules** so `node --test` can import them directly (Node strips the types):
  - reel easing and the drum on/off rule in `reel.ts`;
  - shelf rows and layout in `pantry/shelf.ts`.
- **Browser-only code:**
  - canvas drawing in `pantry/art.ts`;
  - the Matter.js world in `pantry/world.ts`, which receives the Matter module as an argument and never imports it at runtime;
  - the client components that wire them up.
- **The drum:** a sticky stage inside a tall section, driven by a passive scroll listener that writes CSS transforms. Without JS, with reduced motion, or on a short viewport, it falls back to a plain stacked layout.
- **The pantry:** a canvas behind the contact content with `pointer-events: none`. `matter-js` loads with a dynamic `import()` only when the section comes near the viewport.

**Tech Stack:** Next.js 16 (App Router), React 19, Tailwind CSS 4, TypeScript, `matter-js` 0.20 (new), `node:test`, puppeteer-core (`shots.mjs`).

**Spec:** `docs/superpowers/specs/2026-10-11-round-4-design.md`. Read it alongside this plan.

## Global Constraints

- All work happens in `site/` on branch `homepage`. Run every command from `site/`.
- `site/AGENTS.md`: "This is NOT the Next.js you know". Before using any Next API not already used in this repo, read the relevant guide in `node_modules/next/dist/docs/`.
- Copy doesn't change anywhere, except the Special item split (§5 of the spec).
- Colours come only from the tokens in `src/app/globals.css`: forest `#34503f`, cream `#f6ebd9`, sheet `#fff7ec`, manteca `#ffd164`, terracotta `#d9663b`, ink-soft `#5b4a3a`. White (`#fff`) is allowed for the Story photo borders.
- The wobbly shape is `.shape-blob` (`border-radius: 46% 54% 48% 52% / 52% 46% 54% 48%`). No `shape-arch` remains anywhere after Task 6.
- Reduced motion (`prefers-reduced-motion: reduce`):
  - no pin;
  - no reel motion;
  - no physics or drop (the shelf is drawn standing still);
  - no transitions (the existing global rule already kills them).
- `matter-js` is only ever loaded through `import("matter-js")`. Type-only imports are fine.
- The pantry canvas has `pointer-events: none` and `aria-hidden="true"`, and every link in the contact section stays clickable.
- No sideways page scroll at any width from 320px up.
- Phone hero: the headline and the "Pedime algo rico" button are fully visible on a 375×667 first screen.
- Lint rules in force include `react-hooks/set-state-in-effect` and `react-hooks/refs`:
  - never call `setState` synchronously in an effect body (use `useSyncExternalStore` for media queries);
  - never read `ref.current` during render.
- Every commit message ends with a blank line and then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **The narrowest phones (320px wide):** the header row and the pantry shelf row must fit without sideways scroll or items hanging off the shelf. Covered by the `fitRow` 320px test (Task 7) and a `WIDTH=320` run of `shots.mjs` (Task 13).
2. **Short or landscape viewports (e.g. 844×390):** the pinned drum must not clip slide content. A reasonable person expects a normal stacked section there. Covered by the `drumAllowed` height test (Task 4).
3. **Clicking links over the pantry canvas:** the sticker links must work wherever the shelf is drawn. Covered by the `elementFromPoint` check in `shots.mjs` (Task 13).
4. **Fonts not loaded yet when the sprites are drawn:** the labels would render in a fallback font. Sprites are built only after `document.fonts.ready`, which is pinned by a source test (Task 8).
5. **Resizing or rotating the device after the knock:** the shelf must re-lay out for the new width instead of leaving items floating or off-canvas. A `ResizeObserver` rebuilds the world; there's a source test (Task 9) and a manual check (Task 13).

```ts
// Maths for the About Me drum (see Story.tsx). Plain functions so they can be unit tested.

/** Extra screens of scrolling the drum holds the page for (3 photos). */
export const PIN_SCREENS = 1.4;
/** Below this viewport height (px) a slide doesn't fit, so the section stays a plain stack. */
export const MIN_DRUM_HEIGHT = 560;
/** Share of each step the reel rests on a photo before rolling to the next. */
export const HOLD = 0.24;

const clamp01 = (v: number) => Math.min(1, Math.max(0, v));
const easeInOut = (t: number) => (t < 0.5 ? 4 * t ** 3 : 1 - (-2 * t + 2) ** 3 / 2);

/**
 * Scroll progress through the pinned stretch (0–1) → reel position (0 … count−1).
 * It rests on each photo for part of each step, then rolls quickly to the next.
 */
export function reelPosition(progress: number, count = 3, hold = HOLD): number {
  const steps = count - 1;
  const x = clamp01(progress) * steps;
  if (x >= steps) return steps;
  const i = Math.floor(x);
  return i + easeInOut(clamp01((x - i - hold / 2) / (1 - hold)));
}

/** How slide `i` looks when the reel is at `pos`: neighbours shrink, fade and swing. */
export function slideLook(i: number, pos: number, restTilt: number) {
  const delta = i - pos;
  const dist = Math.min(1, Math.abs(delta));
  return {
    scale: 1 - 0.2 * dist,
    opacity: 1 - 0.75 * dist,
    tilt: restTilt + delta * 14,
    current: Math.abs(delta) < 0.25,
    origin: (delta < 0 ? "center bottom" : "center top") as "center top" | "center bottom",
  };
}

/** The drum needs motion allowed and enough height for a photo and its paragraph. */
export const drumAllowed = (o: { reducedMotion: boolean; viewportHeight: number }) =>
  !o.reducedMotion && o.viewportHeight >= MIN_DRUM_HEIGHT;
```

```ts
export const ITEM_INSET = 10; // px from each end of the plank to the first and last package

  row.reduce((t, k) => t + SIZES[k].w, 0) + MIN_GAP * Math.max(0, row.length - 1);

/** Drops items from the right until the row fits between x0 and x1. The knock targets always stay. */
export function fitRow(row: ItemKind[], x0: number, x1: number): ItemKind[] {
  const out = [...row];
  for (let i = out.length - 1; i >= 0 && widthOf(out) > x1 - x0; i--) {
    if (!(KNOCK_TARGETS as readonly ItemKind[]).includes(out[i])) out.splice(i, 1);
  }
  return out;
}

  const total = row.reduce((t, k) => t + SIZES[k].w, 0);
  const gap = row.length > 1 ? (x1 - x0 - total) / (row.length - 1) : 0;
  let x = x0;
  return row.map((k) => {
    const c = x + SIZES[k].w / 2;
    x += SIZES[k].w + gap;
    return c;
  });
}
```

```ts
/** One package centred at (x, y), rotated by angle (radians). */
export function drawSprite(ctx: Ctx, s: Sprite, x: number, y: number, angle: number) {
  ctx.save();
  ctx.translate(x, y); ctx.rotate(angle);
  ctx.shadowColor = "rgba(0,0,0,.18)"; ctx.shadowOffsetY = 2; ctx.shadowBlur = 3;
  ctx.drawImage(s.img, -s.w / 2, -s.h / 2, s.w, s.h);
  ctx.restore();
}

export function addDust(dust: Dust[], x: number, y: number, n: number, spread: number) {
  for (let i = 0; i < n; i++) {
    dust.push({
      x, y,
      vx: (Math.random() * 2 - 1) * spread,
      vy: (Math.random() * 1.3 - 1) * spread - 0.3,
      r: 2 + Math.random() * 4,
      a: 0.3 + Math.random() * 0.3,
    });
  }
}

/** Moves each flour puff on a frame, draws it, and drops the faded ones. */
export function stepAndDrawDust(ctx: Ctx, dust: Dust[]) {
  for (let i = dust.length - 1; i >= 0; i--) {
    const p = dust[i];
    p.x += p.vx; p.y += p.vy; p.vx *= 0.93; p.vy = p.vy * 0.93 - 0.01; p.r += 0.1; p.a -= 0.007;
    if (p.a <= 0) { dust.splice(i, 1); continue; }
    ctx.fillStyle = `rgba(255,250,240,${p.a})`;
    ctx.beginPath(); ctx.arc(p.x, p.y, p.r, 0, 7); ctx.fill();
  }
}
```

```ts
// The physics side of the pantry. Receives Matter as an argument, so it's never bundled up front.
import type MatterJS from "matter-js";
import { KNOCK_TARGETS, SIZES, capPush, type ItemKind, type Kind } from "./shelf";
import { addDust, drawShelf, drawSprite, stepAndDrawDust, type Dust, type ShelfLayout, type Sprite } from "./art";

type Item = MatterJS.Body & { kind: Kind; home?: boolean; dropper?: boolean; hitDone?: boolean };

export function createPantry(M: typeof MatterJS, sprites: Record<Kind, Sprite>, layout: ShelfLayout) {
  const { Engine, Bodies, Body, Composite, Sleeping, Events, Query } = M;
  const engine = Engine.create({ enableSleeping: true });
  const items: Item[] = [];
  const dust: Dust[] = [];
  const pointer = { x: 0, y: 0, px: 0, py: 0, on: false };

  // Shelf top and the section's sides
  const wall = { isStatic: true, friction: 0.8 };
  Composite.add(engine.world, [
    Bodies.rectangle(layout.width / 2, layout.floor + 50, layout.width * 2, 100, wall),
    Bodies.rectangle(-50, layout.height / 2, 100, layout.height * 3, wall),
    Bodies.rectangle(layout.width + 50, layout.height / 2, 100, layout.height * 3, wall),
  ]);

  // The mouse is a small invisible ball that follows the pointer
  const hand = Bodies.circle(-500, -500, 18, { frictionAir: 0, inertia: Infinity, density: 0.005 });
  hand.sleepThreshold = Infinity;
  Composite.add(engine.world, hand);

  const add = (kind: Kind, x: number, y: number, angle = 0) => {
    const { w, h } = SIZES[kind];
    const b = Bodies.rectangle(x, y, w, h, {
      chamfer: { radius: 3 },
      friction: 0.7,
      frictionStatic: 0.9,
      restitution: 0.08,
      density: 0.0016,
    }) as Item;
    b.kind = kind;
    Body.setAngle(b, angle);
    Composite.add(engine.world, b);
    items.push(b);
    return b;
  };

  layout.row.forEach((k, i) => {
    const b = add(k, layout.centres[i], layout.floor - SIZES[k].h / 2);
    b.home = true;
    Sleeping.set(b, true);
  });

  // Whatever a drop hits first gets tipped over, so the opening knock always reads
  Events.on(engine, "collisionStart", (ev) => {
    for (const pair of ev.pairs) {
      const a = pair.bodyA as Item;
      const b = pair.bodyB as Item;
      const [d, o] = a.dropper ? [a, b] : b.dropper ? [b, a] : [null, null];
      if (!d || !o || d.hitDone || !o.home) continue;
      d.hitDone = true;
      Sleeping.set(o, false);
      Body.setAngularVelocity(o, 0.2);
      Body.setVelocity(o, { x: 4.5, y: -2.5 });
    }
  });

  const xOf = (k: ItemKind) => items.find((b) => b.kind === k)?.position.x ?? layout.width / 2;

  return {
    /** The opening knock: the manteca and the arándanos punnet fall onto the two tall targets. */
    drop() {
      const [first, second] = KNOCK_TARGETS;
      const butter = add("manteca", xOf(first) - 6, -40, -0.3);
      butter.dropper = true;
      Body.setVelocity(butter, { x: 1, y: 8 });
      const punnet = add("punnet", xOf(second) - 8, -260, 0.4);
      punnet.dropper = true;
      Body.setVelocity(punnet, { x: 1, y: 8 });
    },
    /** Mouse position relative to the section, or null when it leaves. */
    pointer(x: number | null, y = 0) {
      if (x === null) {
        pointer.on = false;
        return;
      }
      if (!pointer.on) {
        pointer.px = x;
        pointer.py = y;
      }
      pointer.x = x;
      pointer.y = y;
      pointer.on = true;
    },
    /** A tap or click flicks the item under it over, with a little puff of flour. */
    tap(x: number, y: number) {
      const hit = Query.point(items, { x, y })[0] as Item | undefined;
      if (hit) {
        const dir = x < hit.position.x ? 1 : -1;
        Sleeping.set(hit, false);
        Body.setAngularVelocity(hit, 0.22 * dir);
        Body.setVelocity(hit, { x: 4 * dir, y: -5 });
      }
      addDust(dust, x, y, hit ? 8 : 14, 2.2);
    },
    step() {
      if (pointer.on) {
        Body.setPosition(hand, { x: pointer.x, y: pointer.y });
        Body.setVelocity(hand, { x: capPush(pointer.x - pointer.px), y: capPush(pointer.y - pointer.py) });
      } else {
        Body.setPosition(hand, { x: -500, y: -500 });
        Body.setVelocity(hand, { x: 0, y: 0 });
      }
      pointer.px = pointer.x;
      pointer.py = pointer.y;
      Engine.update(engine, 1000 / 60);
      for (const b of items) {
        // Anything that somehow escapes drops back in from the top
        if (b.position.y > layout.height + 200) {
          Body.setPosition(b, { x: layout.width / 2, y: -60 });
          Body.setVelocity(b, { x: 0, y: 0 });
        }
        if (b.speed > 6 && Math.random() < 0.05) addDust(dust, b.position.x, b.position.y, 2, 1.2);
      }
    },
    draw(ctx: CanvasRenderingContext2D) {
      ctx.clearRect(0, 0, layout.width, layout.height);
      drawShelf(ctx, layout.plankX0, layout.plankX1, layout.floor);
      for (const b of items) drawSprite(ctx, sprites[b.kind], b.position.x, b.position.y, b.angle);
      stepAndDrawDust(ctx, dust);
    },
    destroy() {
      Events.off(engine, "collisionStart");
      Engine.clear(engine);
    },
  };
}

export type PantryWorld = ReturnType<typeof createPantry>;
```

```tsx
"use client";

import { useEffect, useRef } from "react";
import type MatterJS from "matter-js";
import { ITEM_INSET, PLANK_OVERHANG, SIZES, fitRow, layoutRow, rowFor, type Kind } from "./pantry/shelf";
import { drawShelf, drawSprite, makeSprites, type ShelfLayout, type Sprite } from "./pantry/art";
import { createPantry, type PantryWorld } from "./pantry/world";

/**
 * The pantry shelf behind the contact section. Decorative: the canvas never takes clicks.
 * It's drawn standing still at first (and always with reduced motion). The physics loads
 * only when the section gets near, and the opening knock plays the first time the shelf is seen.
 */
export default function Pantry() {
  const canvasRef = useRef<HTMLCanvasElement>(null);

  useEffect(() => {
    const canvas = canvasRef.current;
    const section = canvas?.parentElement;
    const shelfLine = section?.querySelector<HTMLElement>("[data-shelf]");
    const ctx = canvas?.getContext("2d");
    if (!canvas || !section || !shelfLine || !ctx) return;

    const reduced = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
    let sprites: Record<Kind, Sprite> | null = null;
    let layout: ShelfLayout | null = null;
    let Matter: typeof MatterJS | null = null;
    let world: PantryWorld | null = null;
    let shelfSeen = false;
    let dropped = false;
    let onScreen = false;
    let frame = 0;
    let cancelled = false;

    const measure = (): ShelfLayout => {
      const s = section.getBoundingClientRect();
      const f = shelfLine.getBoundingClientRect();
      const plankX0 = f.left - s.left - PLANK_OVERHANG;
      const plankX1 = f.right - s.left + PLANK_OVERHANG;
      const x0 = plankX0 + ITEM_INSET;
      const x1 = plankX1 - ITEM_INSET;
      const row = fitRow(rowFor(s.width), x0, x1);
      return { width: s.width, height: s.height, floor: f.top - s.top + 4, plankX0, plankX1, row, centres: layoutRow(row, x0, x1) };
    };

    const drawStill = () => {
      if (!sprites || !layout) return;
      ctx.clearRect(0, 0, layout.width, layout.height);
      drawShelf(ctx, layout.plankX0, layout.plankX1, layout.floor);
      layout.row.forEach((k, i) => drawSprite(ctx, sprites![k], layout!.centres[i], layout!.floor - SIZES[k].h / 2, 0));
    };

    /** (Re)measure, size the canvas, and start a fresh world if physics is ready. */
    const build = () => {
      if (!sprites) return;
      layout = measure();
      const dpr = Math.min(2, window.devicePixelRatio || 1);
      canvas.width = Math.round(layout.width * dpr);
      canvas.height = Math.round(layout.height * dpr);
      ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
      world?.destroy();
      world = Matter && !reduced ? createPantry(Matter, sprites, layout) : null;
      if (world) world.draw(ctx);
      else drawStill();
    };

    const loop = () => {
      frame = 0;
      if (!world || !onScreen) return;
      world.step();
      world.draw(ctx);
      frame = requestAnimationFrame(loop);
    };
    const start = () => {
      if (!frame && world && onScreen) frame = requestAnimationFrame(loop);
    };
    const maybeDrop = () => {
      if (dropped || !shelfSeen || !world) return;
      dropped = true;
      world.drop();
      start();
    };

    // Labels use the site fonts, so draw only once they're loaded
    document.fonts.ready.then(() => {
      if (cancelled) return;
      const css = getComputedStyle(document.documentElement);
      sprites = makeSprites(
        {
          display: css.getPropertyValue("--font-fraunces").trim() || "Georgia, serif",
          sans: css.getPropertyValue("--font-dm-sans").trim() || "system-ui, sans-serif",
        },
        Math.min(2, window.devicePixelRatio || 1),
      );
      build();
      maybeDrop();
      start();
    });

    // Load the physics only when the section is within a screen of the viewport
    const near = new IntersectionObserver(
      (entries) => {
        if (reduced || Matter || !entries.some((e) => e.isIntersecting)) return;
        near.disconnect();
        import("matter-js").then((mod) => {
          if (cancelled) return;
          Matter = mod.default;
          build();
          maybeDrop();
          start();
        });
      },
      { rootMargin: "100% 0px 100% 0px" },
    );
    near.observe(section);

    // Only animate while the section is on screen
    const visible = new IntersectionObserver((entries) => {
      onScreen = entries.some((e) => e.isIntersecting);
      start();
    });
    visible.observe(section);

    // The knock plays the first time the shelf itself scrolls into view
    const seen = new IntersectionObserver((entries) => {
      if (!entries.some((e) => e.isIntersecting)) return;
      shelfSeen = true;
      seen.disconnect();
      maybeDrop();
    });
    seen.observe(shelfLine);

    // A new width or height (rotation, fonts, images) re-lays out the shelf
    let lastW = 0;
    let lastH = 0;
    const resize = new ResizeObserver(([entry]) => {
      const { width, height } = entry.contentRect;
      if (Math.abs(width - lastW) < 1 && Math.abs(height - lastH) < 1) return;
      lastW = width;
      lastH = height;
      build();
      start();
    });
    resize.observe(section);

    const rel = (e: MouseEvent) => {
      const r = section.getBoundingClientRect();
      return [e.clientX - r.left, e.clientY - r.top] as const;
    };
    const onMove = (e: PointerEvent) => {
      if (e.pointerType !== "mouse" || !world) return;
      world.pointer(...rel(e));
      start();
    };
    const onLeave = () => world?.pointer(null);
    // Taps and clicks on anything but a link flick what's under them. Never blocks scrolling.
    const onClick = (e: MouseEvent) => {
      if (!world || (e.target as Element).closest("a")) return;
      world.tap(...rel(e));
      start();
    };
    section.addEventListener("pointermove", onMove);
    section.addEventListener("pointerleave", onLeave);
    section.addEventListener("click", onClick);

    return () => {
      cancelled = true;
      cancelAnimationFrame(frame);
      near.disconnect();
      visible.disconnect();
      seen.disconnect();
      resize.disconnect();
      section.removeEventListener("pointermove", onMove);
      section.removeEventListener("pointerleave", onLeave);
      section.removeEventListener("click", onClick);
      world?.destroy();
    };
  }, []);

  return <canvas ref={canvasRef} aria-hidden="true" className="pointer-events-none absolute inset-0 h-full w-full" />;
}
```

```tsx
import { useEffect, useState } from "react";
import { ChatIcon } from "./icons";
import { WA_HELLO } from "./data";

/**
 * Always-in-reach WhatsApp pill, phones only. It steps aside while the hero's own
 * button is on screen and from the contact section down, where the stickers are.
 */
export default function FloatingWhatsApp() {
  // Hidden at first: the page opens with the hero button in view
  const [hidden, setHidden] = useState(true);

  useEffect(() => {
    const targets = [document.querySelector("[data-hero-cta]"), document.getElementById("contacto")].filter(
      (el): el is Element => el !== null,
    );
    const onScreen = new Map<Element, boolean>();
    const io = new IntersectionObserver((entries) => {
      for (const e of entries) onScreen.set(e.target, e.isIntersecting);
      setHidden([...onScreen.values()].some(Boolean));
    });
    targets.forEach((t) => io.observe(t));
    return () => io.disconnect();
  }, []);

  return (
    <a
      href={WA_HELLO}
      data-floating-wa=""
      aria-hidden={hidden}
      tabIndex={hidden ? -1 : undefined}
      className={`btn-pop fixed right-4 bottom-5 z-50 inline-flex min-h-[52px] items-center gap-2 rounded-full bg-forest pr-5 pl-4 text-[15px] font-bold text-cream transition-[opacity,transform,translate] duration-300 md:hidden ${
        hidden ? "pointer-events-none translate-y-6 opacity-0" : ""
      }`}
    >
      <ChatIcon filled />
      Escribime
    </a>
  );
}
```
