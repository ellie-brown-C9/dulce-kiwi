# Round 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Switch the yellow to manteca `#ffd164`, make the header a centred masthead, turn the story photos into a then-and-now timeline, and rebuild contact as jar labels with a badge footer. Then publish to dulcekiwi.com.

**Architecture:**
- **Colour:** a token rename in `globals.css` plus a mechanical `butter`→`manteca` swap across components.
- **Sections:** three section rewrites (`Header`, `Story`, `Contact`), each self-contained. `Contact` reuses `Wave`, and gains two icons in `icons.tsx`.
- **Checks:** source-level guard tests in `tests/brand.test.mjs`, the existing `shots.mjs` layout check, and a look at the screenshots.

**Tech Stack:** Next.js 16.2.9, React 19, Tailwind CSS v4 (individual `rotate`/`translate`/`scale` properties; `transition-transform` covers them), Node 25 `node --test`, puppeteer-core + local Chrome, Vercel CLI.

**Spec:** `docs/superpowers/specs/2026-10-09-round-2-design.md`

## Global Constraints

- **Manteca:** `#ffd164`, token `--color-manteca`. No `butter` token or class names remain anywhere in `src/`.
- **Contrast:** no terracotta text on manteca.
- **Header:** the stacked wordmark without the kiwi, `/brand/wordmark-stacked-green.png` (1200×874). The kiwi version is never used in the header.
- **Footer:** the round kiwi badge `/brand/badge-kiwi.png` (1200×1200), 72px, 3px manteca ring, rotated −8°. No menu links in the footer. No stacked logo in the footer.
- **Contact:** the section must not get taller than the current one. The "Escribime por WhatsApp" button and the area line under the contacts are removed.
- **New copy is exactly:** "escribime por WhatsApp", "seguime en Instagram", "o mandame un mail". Everything else keeps its current words.
- **Phone:** no hamburger menu. The header's Pedir pill is hidden below `md` (the floating WhatsApp pill covers it).
- **Dev server:** this Windows dev server doesn't hot-reload `globals.css` reliably. Restart it with `.next/dev` cleared before every visual check.

## Review Focus

1. **Phone header (390px).** The three menu links must fit in one row without sideways scroll. Covered by the `scrollWidth` check in `shots.mjs` (Task 5) plus a phone screenshot look.
2. **Long contact values on phone.** `hola@dulcekiwi.com` inside a tilted label must not overflow or push the page wider. The `scrollWidth` check covers this (Task 5), along with `min-w-0`/`break-words` on the value (Task 4).
3. **Contact links.** Each label must open WhatsApp, Instagram and mail directly. Covered by the rendered-HTML href check in Task 4.
4. **Timeline photos on phone.** The three photos and their captions must stay in one row, with captions wrapping instead of overflowing. Covered by the scrollWidth check and the phone screenshot (Task 5).
5. **Reduced motion.** The label hover transforms are transitions and the ticker is an animation, so both must turn off. Covered by the existing reduced-motion pass (Task 5).
